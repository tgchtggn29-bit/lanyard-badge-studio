用你的 AI 智能体做工牌
装上技能，说一句话就出整套工牌、名片、视频和印刷文件
—
  1. 下载项目并进入目录
    git clone https://github.com/tgchtggn29-bit/lanyard-badge-studio
cd lanyard-badge-studio && npm install
  2. 启动 Claude Code，技能 badge-studio 会自动加载
    claude
  3. 把 Logo 放进文件夹，直接说
    帮我做一套公司工牌：品牌叫「你的品牌」，Logo 在 ./logo.png，蓝白配色，要专业一点；员工名单在 people.csv，顺便出名片和印刷文件
想在任何目录都能用：把技能装到全局
mkdir -p ~/.claude/skills && cp -r .claude/skills/badge-studio ~/.claude/skills/
Windows：
xcopy /E /I .claude\skills\badge-studio %USERPROFILE%\.claude\skills\badge-studio
  1. 下载技能包 badge-studio.zip ↓
  2. 打开 Claude（网页 / 桌面 / 手机），在设置里找到技能（Skills），上传这个 zip
  3. 新建对话，上传 Logo 和品牌资料，说
    用 badge-studio 技能，帮我们公司设计一套工牌和名片
技能包里带了渲染引擎和脚本。对话环境能运行代码时，Claude 会直接出预览图；也可以让它把 brand.json 给你，点左上角「导入配置」在这里查看和下载。
  1. 用 Codex / Cursor / Windsurf / Trae / 通义灵码等打开本项目文件夹，智能体会读取 AGENTS.md
  2. 对它说
    先读 .claude/skills/badge-studio/SKILL.md，然后帮我设计公司工牌：品牌叫「你的品牌」，Logo 在 ./logo.png
支持 Skills 目录的智能体（如 OpenClaw 等）：把 .claude/skills/badge-studio 复制到它的 skills 目录即可。
没有智能体也行：把需求和当前配置复制给 ChatGPT / 豆包 / DeepSeek / Kimi 等任何 AI，再把它返回的 JSON 粘贴回来。
