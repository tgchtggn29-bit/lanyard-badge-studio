# 设计笔记 · 每个细节为什么这样调

这套动效是对照一条真实的「AI 公司工牌掉落」录屏一帧一帧调出来的。下面记录每个参数的来由，方便你改的时候知道动的是什么。

## 时间线（默认 7.6 秒一循环）

| 时间 | 发生什么 | 参数 |
|---|---|---|
| 0 – 0.3s | 空白页，只有左上 / 右上小字 | — |
| 0.3 – 1.2s | 标签浮现：上半组从上往下、下半组从下往上，依次淡入 | `tags` 前一半 / 后一半 |
| 1.2 – 1.8s | 背景大字逐个字母从下弹起 | `giantWord` |
| 1.55s | 底部品牌字弹出 | `pulse` |
| 2.0s | 工牌开始掉落（0.36s，带动态模糊） | `motion.dropAt` `motion.fall` |
| 2.36s | 挂绳拉住：往下多冲一点再回弹；卷尺扣细绳被扯长后缩回 | 内置 |
| 2.4 – 4.0s | 左右大幅晃两下，卡片比挂绳慢半拍，带立体翻转和反光移动 | `motion.swing` `cardLag` `twist` `damping` |
| 4.0s 之后 | 停稳后轻微呼吸晃动，标签也在漂 | 内置 |
| 4.55s | 品牌字放大再缩回、发光 | `motion.pulseAt` |
| 6.5s | 工牌被拉回上方，标签和大字散开 | `motion.exitAt` |
| 7.6s | 回到空白页 → 无缝循环 | `motion.duration` |

`motion.settleAt`（默认 4.2s）是「最稳的一帧」：预览图、以及所有 `cover_*` 视频和 GIF 都从这一帧开始播。

## 物理模型

不是真物理引擎，是**手调的阻尼振动**，因为需要每次结果一致、可循环：

```
挂绳角度   θ(τ) = swing   · e^(−d·τ)      · sin(7.6τ − 0.28)
卡片相对角 φ(τ) = cardLag · e^(−1.31d·τ)  · sin(7.6τ − 1.25)    ← 相位落后 ≈ 卡片慢半拍
立体翻转   ψ(τ) = twist   · e^(−1.1d·τ)   · sin(10τ + 0.4)       ← 用 X 方向缩放 + 轻微斜切模拟
回弹       y(τ) = 38 · e^(−7τ) · sin(15τ)
细绳伸缩   c(τ) = 58 · (τ/0.11) · e^(1 − τ/0.11)
```

- 周期 ≈ 0.83s，`damping = 1.45` 时晃两下后幅度降到 5% 以下，正好是原片「左右晃荡两下再停」的感觉。
- 反光高光的位置跟着 ψ 走，翻转越大越亮。

## 动态模糊

每帧在 0.65 帧时长内取 8 个子时刻，依次以 1/k 透明度叠加（等效平均）。掉落和大幅摆动时有拖影，停稳后完全清晰。预览图 / 印刷稿不加模糊。

## 清晰度

- 引擎在 720×1280 的逻辑坐标里画，导出时整体放大：1080P = ×1.5，4K = ×3，所以文字和线条在任何分辨率都是矢量级清晰。
- 视频用 x264 `-tune animation`，1080P CRF 14 / 4K CRF 16（黑底荧光小字在默认 CRF 23 下会糊）。

## 社媒细节

- **首帧即封面**：iPhone 相册 / 微信不能自选视频封面，固定取第一帧，所以成片从停稳帧开始、循环 3 次后停回同一帧。
- **GIF**：先出 720 宽 20fps 高清版；再按 `[640/15fps/128色] → [640/12/96] → [560/12/96] → [480/12/64] → [400/10/64]` 阶梯压缩，取第一档小于 `--gif-limit`（默认 10MB，公众号上限）的。
- **网址**：小红书会因画面里出现网址判违规。`findUrls()` 扫描配置所有文字。

## 卡面版式

正面以 272×370 为参考网格，按宽度等比缩放；印刷尺寸（54×85.6mm）更瘦高，多出的高度全部给中间图案区，头部和底条位置不变，所以动画里的卡片和印出来的卡片是同一套设计。
