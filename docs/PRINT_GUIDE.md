# 印刷对接指南 · 把工牌交给印刷厂 / 物料店

```bash
npm run print -- --config brand.json --people people.csv
```

把生成的 `out/<品牌>/print/` **整个文件夹**发给印刷厂即可。

## 文件说明

| 文件 | 给谁 / 做什么 |
|---|---|
| `01_工牌正面_裁切线.pdf` | 正面印刷文件，带四角裁切线和文件信息 |
| `02_工牌背面_裁切线.pdf` | 背面（默认姓名 / 职位） |
| `03_工牌正反面_出血版_无裁切线.pdf` | 有些厂要求不带裁切线、自己拼版，用这个 |
| `04_工牌背面_批量_裁切线.pdf` | 用了 `--people` 时生成：每位员工一页 |
| `批量背面/*.png` | 同上，每人一张 600dpi 原图 |
| `0x_*_出血_600dpi.png` | 位图原图，做其他物料（贴纸、胸牌）可用 |
| `05_挂绳_20x900mm.pdf / .png` | 挂绳热转印图，含 2mm 出血 |
| `06_设计规范.pdf` | 尺寸、色值、字体、工艺、文件清单 —— 印刷厂最需要看的一份 |
| `给印刷厂的说明.txt` | 纯文本版要点，方便直接贴到微信里 |

## 默认规格（都可以改）

| 项目 | 默认 | 参数 |
|---|---|---|
| 卡片成品 | 54 × 85.6 mm 竖版（标准 CR80 卡） | `--card 54x85.6` |
| 出血 | 每边 3 mm | `--bleed 3` |
| 分辨率 | 600 dpi | `--dpi 600` |
| 挂绳 | 20 × 900 mm | `--lanyard 20x900` |

常见其他尺寸：大号竖版胸卡 `--card 60x90`，会议证 `--card 90x120`，15mm 窄挂绳 `--lanyard 15x900`。

## 和印刷厂确认的 5 件事

1. **荧光色**：荧光绿、荧光粉这类颜色，普通四色（CMYK）印刷印不出来，会偏暗偏黄。要求用**荧光专色油墨**或指定**潘通（Pantone）专色**，并**先打样**对色。
2. **CMYK 数值是参考**：设计规范里的 CMYK 是公式换算，不同纸和机器会有差异，以打样为准。
3. **圆角**：卡片建议模切 R3mm 圆角；文件里是直角 + 出血，圆角由厂里模切。
4. **材质**：PVC 0.76mm（耐用）或 300g 铜版纸覆哑膜（便宜，插卡套用）。
5. **卡套和挂绳配件**：透明硬胶卡套（内径比卡大 1–2mm）、伸缩易拉扣、金属钩，一般物料店可以一起配。

## people.csv 格式

```csv
name,title,id,note
张三,产品经理 / PM,NO. 0001,凭此卡出入活动现场
李四,设计师 / Designer,NO. 0002,凭此卡出入活动现场
```

用 Excel 编辑后「另存为 CSV UTF-8」即可。
